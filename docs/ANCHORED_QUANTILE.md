# 以强融合函数初始化的神经—核联合分位数模型

本轮开发一个完整候选，沿用原分位数TabM逐环境已选结构、成员与99分位点，以及原Huber的折内材料核和环境核。没有新增教师体系。现役冻结融合外层PCC 0.526506保持原有定位。

初始化在每个成员最后一个独立线性头上一次性吸收`T=I-11'/198`（权重/偏置沿输出轴减半个均值）；不保留永久输出变换层。核初始化为原Huber函数的一半，神经成员点预测的一半加核初始化必须逐材料等于历史固定融合，容差1e-6；原神经与Huber分别重建并对照保存预测。分位点差值不变，不据此声称概率校准。

主目标：`mean_environment(mean_material,member(sum_99 pinball)) + lambda_neural/2 * sum_trainable_parameters (theta-theta0)^2 + lambda_kernel/2 * ||delta_g||_RKHS^2`。theta0是输出头变换后的起点，神经正则是原始参数平方和，不除以参数数；preprocessing buffers固定、不计入。核截距固定在初始化值，不更新或惩罚它；RKHS只学习材料—环境位置修正。核由折内表型标准化换算到各神经分支尺度，保留原有函数，不把原始核系数欧氏长度当作RKHS范数。

三组预定系数：`(.001,1)`、`(.01,10)`、`(.1,100)`，分别为神经与核正则。原AdamW配置学习率乘0.1；额外weight_decay固定0，L2-SP显式进入目标。四环境确定性全批前向（eval关闭dropout但保留梯度），每个成员分别计算pinball；各网络裁剪阈值5。

每条联合轨迹固定20次神经更新，保存t=0及每次更新后的同步状态。t=0是原融合函数，不要求它是新的kernel目标最优点。第一次神经更新前先求核子问题；神经更新固定当前核，使用原非光滑目标的有效神经块次梯度，不声称它是精确的剖面/包络梯度。每次神经参数更新后重新求解核到验收精度，再保存两分支。没有对旧Huber光滑包络梯度的复用。

核子问题采用原始pinball目标的ADMM分裂：每个材料—环境位置的prox利用排序后的成员×分位点残差断点求精确解；二次RKHS步利用可分离K和B的谱分解，不展开巨型Gram。核特征保留材料谱>1e-12，与原Huber构造一致；组合核谱<=1e-12按数值零处理。每次求解记录原始/对偶目标、相对Fenchel间隙、ADMM原始及对偶残差、迭代数；仅相对间隙在[-1e-10,1e-10]才返回，达到10000次上限不视为收敛。初始ADMM rho=.1，不用验证集调求解精度。需通过训练侧的更严格容差预测稳定性核验。

预算：30开发单元×2种子×3正则=180条四环境联合轨迹（720环境—种子实例），每条20次神经更新；原模型只按已有各内折最佳轮数重建。固定原结构，不重做8配置搜索。每个候选时刻保存逐材料点预测、四网络权重、核初始参数及修正系数、拟合材料ID、核结构、求解证书。

每外折从三正则×21时刻中共同选一个(c,t)，按三个内折、四环境、双种子平均预测的12个PCC平均选取；平局按配置顺序及较早时刻。不分别选内折/环境/种子checkpoint，不再对最佳轮次取中位数。报告完整共同步曲线、原分位数、初始固定融合与候选的PCC/RMSE/MAE；开发选模增益不视为独立泛化证据。若回到t=0则未建立联合学习优势。本轮授权开发比较，不自动启动外层或追加搜索。

必要验收：小规模子问题与通用SLSQP凸问题对照目标及预测；PSD秩亏情况和未收敛拒绝；初始化函数一致；确定性、同步核状态、权重重载；共同(c,t)选择。正式运行前只在训练侧做求解耗时/精度检查，不利用验证成绩改变候选。

训练侧数值验收：真实首个拟合集的一步联合过程，初始化最大差1.41e-7。核子问题以1e-10为相对间隙阈值时80次ADMM迭代；收紧到1e-12为160次，训练核位置最大差1.85e-6。正式容差在观察验证成绩前固定为1e-10。该计时/精度检查产物位于omen /tmp/anchored-training-side-check及/tmp/anchored_precision_result.json，不作性能结果或提交到Git。
