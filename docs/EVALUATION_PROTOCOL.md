# Wheat599 统一评价协议

本文件是 Wheat599 主比较的现役协议。历史五折、单次验证和其他设置保留原始结果，不自动归入主表。唯一划分来源为 [`splits_manifest.json`](../results/get_icm_protocol_20261103/splits_manifest.json)；不重新抽取折或从测试结果挑选划分。

## 数据、任务与划分

使用发布版 `wheat.X`（599×1279，0/1 DArT）及 `wheat.Y`，保持材料和标记原始顺序；Env1–Env4 对应原始表型列 `1、2、4、5`。主比较仅使用标记，不引入谱系矩阵或外部数据。

预测目标为：给定完全留出的新材料基因型和目标环境标识，预测该材料在四个已知环境中的产量。训练材料的四环境表型均可使用；测试材料四环境表型全部留出。单环境模型与多环境模型均可参与，额外输入另列。

每个外折留出 59–60 份测试材料，539–540 份为开发材料；每个外折内的三折分别含约 359–360 份拟合材料和 179–180 份验证材料。清单中的十外折对应 `default_rng(42).permutation(599)` 后切成十份，不等同 `sklearn KFold(random_state=42)`；各外折内层是对应开发材料上的 `KFold(3, shuffle=True, random_state=42+fold)`。2026-11-12 已按材料 ID 复核全部 10 个外折和 30 个内折。实际运行只读清单，以清单 ID 为准。

## 训练与选模

- 所有标准化、特征筛选、分组、核参数、环境相关矩阵等，只从当前拟合集估计；验证和测试只应用该变换。预测和误差还原到发布版 `wheat.Y` 尺度，不使用测试折表型重新缩放。
- 每个外折仅根据其三个内折选择配置。独立环境模型按对应环境三折平均 PCC 选择；联合四环境模型按三折、四环境宏 PCC 选择。同分按运行前固定的配置顺序取首项。开发分数属于选模结果。
- 随机模型主比较使用种子 `42、2026`，两种子预测平均；同时保留各单种子预测及指标。确定性模型运行一次。内部集成成员不是独立训练种子。
- 采用 epoch 早停的模型，各种子分别在内折早停，按种子平均预测选择配置。选定后，各种子分别取三个内折最佳 epoch 中位数，在完整外折开发集从头重拟合；学习率调度与重拟合预算一起固定。多阶段模型逐阶段确定预算。预训练、蒸馏、学习型融合和校准均纳入折内流程；预固定等权融合可复用对应基模型的预测。不能使用测试材料表型训练教师、选择权重或拟合校准。
- 不统一优化器、损失、batch size、裁剪或配置数。每个模型运行前记录搜索空间和算法、训练上限、早停、聚合方式和计算预算；默认与调优配方分列。预算不匹配时仅解释完整系统差异，不能直接归因为架构。

## 评分、报告与历史数据

每个外折配置和预测固定后评分。主指标是 40 个环境—折的 PCC 等权平均，RMSE、MAE 同口径；主表同时给出四环境 PCC、种子数和搜索预算。附表给出十个外折配对差，以及各环境合并 OOF 指标；不得混称折均与合并 OOF。非有限预测或常数预测引起的无定义 PCC 明确报告，不删折或用 `nanmean` 隐藏。

只有满足本协议且产物可核验的历史结果可复用并纳入统一主表。划分、开发材料预算、种子或选模规则不符者保留在历史表；需要进入主表时才按本协议重评。目前已确认可复用的主表预测为 Huber ICM、分位数 TabM 和预固定等权融合，核对见 [统一比较准备](MULPHE_UNIFIED.md)。其他历史条目在逐项核实前保留历史口径；“尚未核实”不等同于已认定不符合。历史模型及其原评价口径见 [模型对比](MODEL_COMPARISON.md)。

十折训练集相互重叠、四环境相关，40 个分数不是独立重复，不据此计算独立样本 p 值或置信区间。本协议规范后续比较，但已有折已反复用于研究反馈，不能视作新独立测试集。关于训练侧预处理见 [scikit-learn 文档](https://scikit-learn.org/stable/common_pitfalls.html)；折间误差相关与方差估计限制见 [Bengio 与 Grandvalet, 2004](https://www.jmlr.org/papers/v5/grandvalet04a.html)。
