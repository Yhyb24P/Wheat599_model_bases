# Wheat599固定分组核：第一阶段

用户附件 `b88b549e-375a-4cb2-bf4e-6c02a06e8ddc/pasted-text-1.txt` 授权。本轮仅Wheat599，先验证固定分组；未通过则结束，不开发神经权重、不进入外层。附件中的GLS局部导数尚未独立复算，不能作为有限步长的预测成绩。

复用原30个内层单元。每单元使用`heterogeneous_icm_development_20261103/base_choices.json`的`homogeneous`基础核参数，以及`robust_icm_development_20261103/selection.json`中本外折已选定的Huber eta、delta和multiplier；不重新搜索。不能误用selection中的完整dev `base`代替该inner的base。先复算原Huber预测指标并与validation.csv逐项对应。

固定tau=0.25，64个相关性锚点组；保留全部标记的原加性核、全局RBF和环境协方差。对照包括原Huber、相关性分组、六个固定种子的频率匹配随机分组，各随机组分别拟合再平均指标，不把平均核当平均模型。分组、频率层、组方差权重均只用fit材料；随机组保持每组在每个频率层的标记计数。组内距离尺度固定为全局fit距离中位数乘该组方差占比；fit常量不进入组核距离，全局核保持原实现。随机种子101/202/303/404/505/606，频率使用10个等宽层。这是明确的新尺度定义，不声称复现不可得的附件导数脚本。

第一阶段预算为30×(1+1+6)=240次多环境Huber拟合，无参数网格。沿用原Huber求解精度，固定每单元原已选配置在optimization.json中保存的四环境阈值，不随新核重新估计MAD；使第一阶段只替换材料核。原基线重新计算的阈值须与保存值核对。

预定继续条件：相关性分组相对原Huber和六个随机系统的平均，宏PCC均至少增加0.001，且两项均至少7/10开发集提高；全部拟合成功并报告四环境PCC/RMSE/MAE。未满足则结束，不追加tau搜索。通过后才确定共享小网络及单参数收缩对照的具体预算；第二阶段尚未达到启动条件。四独立TabM开发0.491874保留为强神经参照，外层0.508190与Huber外层0.521745不混入本阶段开发评分。
