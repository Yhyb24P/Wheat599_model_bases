固定tau=0.25，64个相关性锚点组；保留全部标记的原加性核、全局RBF和环境协方差。对照包括原Huber、相关性分组、六个固定种子的频率匹配随机分组，各随机组分别拟合再平均指标，不把平均核当平均模型。分组、频率层、组方差权重均只用fit材料；随机组保持每组在每个频率层的标记计数。组内距离尺度固定为全局fit距离中位数乘该组方差占比；fit常量不进入组核距离，全局核保持原实现。随机种子101/202/303/404/505/606，频率使用10个等宽层。这是明确的新尺度定义，不声称复现不可得的附件导数脚本。

第一阶段预算为30×(1+1+6)=240次多环境Huber拟合，无参数网格。沿用原Huber求解精度，固定每单元原已选配置在optimization.json中保存的四环境阈值，不随新核重新估计MAD；使第一阶段只替换材料核。原基线重新计算的阈值须与保存值核对。

## 第二阶段：同证据权重（实现中，运行前冻结）

第一阶段达到继续条件后，仅比较identity、单参数收缩和共享小网络。固定原30内层单元、tau=0.25、分组规则、基础参数、原Huber阈值；每单元三种权重各进行一次完整非可分核Huber拟合，共90次（identity用于核对求解器等价性），另有60次小权重学习。没有外层、超参数网格或追加种子。

对每个fit内部，两个固定support/query划分（701、702，support占2/3）用于权重训练。证据只在support内部用11/22/33三个分半计算：组核与表型相似度的相关性，减去全局核与表型相似度的相关性，然后按环境跨组标准化。query表型只进入训练损失。最终在完整fit重算同样证据，再进行Huber拟合；真正的val仅评分。模型API只接收X_fit/Y_fit/X_val，不能读取Y_val。

单参数r=tanh(beta*z)，beta初值0，每步投影到[0,2]。小网络对所有组/环境共享，输入z、log组方差权重、环境one-hot，隐层8/Tanh，输出一维、末层零初始化，r=tanh(logit)。两者均w=softmax_g(log omega+r)，D=sqrt(w/omega)，因此正、有界且每环境sum omega*D²=1。两种学习器均100步Adam、lr=.01、初始化seed42，每步平均两个support/query损失，无验证早停。零方差组不参与。

训练代理为单环境kernel ridge（带未惩罚截距）的query MSE；最终评价为完整多环境非可分核、原Huber阈值和原正则强度。两者目标不同，代理loss不能作为预测增益证据。完整目标为(sum Huber + ridge*||w||²/2)/(n*4)，含四环境截距；identity预测须与第一阶段相关性分组预测最大差不超过1e-4，不能把近似可分核当作Dg不同的完整模型。

预先固定去留：网络相对identity和单参数收缩，宏PCC均至少增加0.001、均至少7/10开发集提高，才建立本轮神经权重收益；且开发PCC超过四独立TabM的0.4918739714，才进入后续外层冻结。否则结束本配置，不追加搜索。报告全部环境PCC/RMSE/MAE、训练时间及失败，不按表现挑环境。仅gpt66启动正式任务，cn写权重模块和测试，gb只读核验。
