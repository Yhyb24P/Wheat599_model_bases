## rtdl FT-Transformer 的正确用法（已用 venv 验证）

`LinearEmbeddings` 是**逐特征**的 weight/bias，形状 `(n_features, d_embedding)`，输出 `(batch, n_features, d_embedding)`：`token_j = x_j * weight_j + bias_j`。对 0/1 标记即 `t_j(0)=b_j`、`t_j(1)=b_j+w_j`，**正是协议要求的逐标记两向量编码**；不需要自定义 tokenizer。

```python
from rtdl_revisiting_models import FTTransformer
model = FTTransformer(
    n_cont_features=X.shape[1],   # 1279
    cat_cardinalities=[],
    d_out=1,
    n_blocks=n_layers,            # 1 or 2
    d_block=d_token,              # 16 or 32
    attention_n_heads=4,          # fixed; divides 16/32
    attention_dropout=dropout,
    ffn_d_hidden_multiplier=4/3,
    ffn_dropout=dropout,
    residual_dropout=0.0,
)
out = model(x_cont=torch.as_tensor(X, dtype=torch.float32), x_cat=None)
```

- 训练：AdamW、batch 64、MSE、max 200、patience 20；内层 valid 早停；refit epochs = inner best epoch 中位数。
- 记录 `best_epoch_`，runner 聚合 median。
- d=16/32、1–2 层是本项目自主小模型选择，不是论文默认（3 层/192/8 头）。
