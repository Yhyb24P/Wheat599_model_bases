# 联合核分位数：Wheat599 开发比较

只使用现有十折中的三重内层材料划分。每个内层拟合集沿用该拟合集内部选择的加性／RBF 材料核及标记标准化，对目标环境分别按拟合集均值和标准差标准化；环境核为 `(1-eta) I + eta corr(Y_fit)`，三种状态均使用 `eta=[0,0.3,0.6,0.8]`。验证材料的所有表型只用于评分，外层测试不参与。

三个分位点核为全 1（共享）、RBF（平滑，固定 `gamma=16`）、单位阵（独立），分位点沿用 `linspace(0.001,0.999,99)`。平滑核相邻分位点相关约 0.99834，下降至 `exp(-1)` 的距离为 0.25；平滑状态仅有一个 γ，不额外搜索 γ。正则系数按核谱尺度预先固定：共享为 `[1e-5,1e-4,1e-3]`，其他状态为上述数值乘其分位点核最大特征值再除以 99。三种状态使用同一目标函数中定义的 λ，但实际数值不同；每个状态独立在 4 个 eta × 3 个 λ 中选配置。共 36 个配置 × 30 内层单元 = 1080 次求解。

对偶变量 α 按 `1/(n*4*99)` 归一化并维持每环境—分位点的盒约束及材料维零和。每个截距采用使训练 pinball 最小的经验分位数；最优截距为区间时取中点。对偶间隙按 `max(1,|P|,|D|)` 归一化，α 的盒约束与零和残差均不超过 `1e-10`、间隙不超过 `1e-6` 才验收；实现内部使用未缩放变量 β，报告残差前乘 `1/(n*4*99)`。最多 200000 次迭代，未收敛明确报告失败，不用验证分数决定何时停止。输出 99 分位点并等权平均后反标准化；也提供预合并系数的单核点预测公式。

小规模测试将三个状态与 SciPy 通用约束优化器求得的原始二次规划对照，检查原始目标、可行性、预测及共享端点；另检查秩一核与 Kronecker 运算、零和投影及未收敛错误。拟合集单设置容差试算中，间隙从 `1e-6` 收紧至 `1e-7`，三个状态平均点预测最大变化依次为 0.000466、0.000089、0.000066 个目标标准差；这是一个拟合集与各状态一个配置，不代表其他配置的误差保证。

各状态分别以三个内折的四环境宏 PCC 选择 eta 和 λ，同时保留每一固定配置的逐折结果；与原分位数 TabM、Huber 及固定融合比较。曲线保存在 omen，不入 Git。由于同一开发材料先前已用于原模型选择，该比较仍是探索性开发结果，不进入外层或改变冻结融合。
