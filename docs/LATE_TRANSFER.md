# 独立 TabM 的后期跨环境迁移

以 `82f6689` 的逐环境选择四独立 TabM 为历史 PCC 参照，比较同一组新拟合专家的四种读出。四格结果保留的早停和容量差异见 [RESULTS.md](RESULTS.md)。本候选的研究问题是辅助环境的独立神经表示，能否在四个专家的标量预测之外提高目标环境精度。

每个环境单独训练原始全标记 TabM，沿用逐成员 MSE。冻结编码器后，将最后隐藏层的成员表示拼成一个向量，为其他目标拟合带岭惩罚的线性输出层。每个输出都在相应目标的表型尺度上。这样，不同拟合中的隐藏坐标无需对齐。第二阶段以本环境原预测为起点，对残差拟合一个小型岭回归。四项系统共享同一批专家与种子：

| 系统 | 残差读出的输入 |
|---|---|
| independent | 直接采用冻结专家 |
| self_calibration | 本环境专家预测 |
| score_transfer | 全部专家各自的表型预测 |
| hidden_transfer | 在 score_transfer 基础上加入其他三个编码器为本目标做出的预测 |

训练第二阶段使用当前 inner fit **内部**的三折交叉拟合。每个子折独立拟合标准化、全部编码器及迁移头。只有未参加该子折任何拟合的材料才提供该子折的二层输入。汇合这些预测后拟合二层系数。对 inner validation 查询，专家和迁移头在整个 inner fit 内重拟合，只接收查询标记。三个原有 inner validation 互相隔离，外层测试材料不进入本实验。每次拟合先按成员、种子平均，再拟合或应用二层读出。

首次比较预先固定源配置为既有列表中的索引 2，四环境一致，两个种子，24 epochs。它以相同训练预算比较四种读出。历史强参照保留了独立选模与早停，另列于结果中。迁移头按中心化隐藏 Gram 平均对角归一后使用岭系数 1。二层特征用其交叉拟合均值和标准差缩放，按平均残差平方损失使用岭系数 0.1。全十个开发集、三内层，原型和配置在观测本轮成绩前冻结。

```bash
python scripts/run_background_nested.py --config configs/late_transfer.yaml --out results/late_transfer_development_20261105
```

结果记录每个 inner 单元的指标、预测文件 SHA 和可重新加载的完整预测器。模型与材料级预测保存在运行端。使用 `wheat599.late_transfer.load_predictor(path)` 可直接根据新材料的标记矩阵推断。

方法近邻包括 [Mul-PheG2P](https://doi.org/10.1111/nph.71461) 的独立编码与后期融合，以及[堆叠式多目标回归](https://arxiv.org/abs/1211.6581) 的折外预测训练。按源学习目标尺度的迁移头、固定独立预测残差和同源读出对照是本次适配的具体选择。
