# 逐层交互读取分位数 TabM：Wheat599 开发比较

在四环境独立的全标记模型中，按拟合集标准化标记，使用 32 维 NFM 成对交互基 `m=RMSNorm(0.5*((zV)^2-z²V²))`；一阶路径使用成员输入、输出缩放，形成初始状态。每个成员的三个残差块均以当前状态和相同交互基计算逐维 sigmoid 门，将该层独立投影的交互基注入状态后，再经过 RMSNorm 和 TabM BatchEnsemble 非线性块。最终使用独立成员的 99 分位输出和原逐成员 pinball 损失；不使用四流或核预测。交互因子、各层门和交互投影与其余网络联合训练。

各层交互投影是带偏置的仿射变换；同一层的门控上下文与注入后的残差块共用该层 RMSNorm 的可训练参数。这两点是当前实现对研究草图的具体适配。

沿用四流研究的八组候选、Muon／AdamW 分组、独立学习率和训练协议；逐层模型固定三块。十折开发集各有三个内折、四环境、两个种子，共 1920 次拟合；每环境以三个内折的双种子平均预测 PCC 选配置。额外读取已核验的原分位数 TabM、原 TabM＋Muon、四流＋Muon 和固定分位数–Huber 融合的逐折结果。四流和逐层模型都采用现有 32 维交互、三块、同一训练预算，但门控、残差组织、参数量有所不同；原 TabM 的输入层 Muon 分组与这两者不完全相同。比较用于判断完整系统，而非单个组件的因果效果。

外层测试不参与训练、checkpoint 或配置选择。保存每配置逐材料点预测、轨迹和模型参数量；原分位数和融合预测按现有哈希核验。开发集多次用于模型选择，开发优势不是独立确认；本轮不追加 NFM/DCN 基线、门控或秩消融，也不自动进入外层。

本批已完成 1920/1920、0 失败。逐层模型开发 PCC 0.494997、RMSE 0.872148、MAE 0.673320；四流候选分别为 0.495884、0.870317、0.670940。ds 独立复算与选模核验通过，详见 [RESULTS](RESULTS.md)。
