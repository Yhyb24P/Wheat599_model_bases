# MeNet 关系表示＋全标记分位数 TabM

本轮以一个双表示完整候选检验：性状感知材料关系能否在隐藏特征层补充全标记神经预测。现役冻结融合不变，外层 PCC 0.526506 是参照；本轮不是 MeNet 原论文成绩复现。没有把新的样本关系称作因果关系，也不重新开启交互摘要、输出正则或核分位数路线。

上游固定 GANLAB/MENET Version2.0 commit `06456e4542ab26716c4db8dd8f17517aa5155ff4`。原样动态加载 `TraitSpecificEncoderForRepGeno`、`RepGeno` 与 `CrossInformationFeatureFusion`；源码、数据和权重均不复制到 Git。Copyright, GANLAB。其 Academic Use Licence 限定内部非商业学术研究，不将我们的适配描述为可自由分发的官方实现。论文：https://doi.org/10.1016/j.xplc.2025.101620 。

阶段一沿用官方三段卷积残差性状编码器，stride=2、embedding=128、AdamW lr=0.01、weight_decay=0.01、batch=32、5 epoch、margin=0.1。使用当前拟合集全部1279原始二值标记，固定现有列序，不赋予列邻接生物学解释。表型只按拟合集均值/标准差缩放。每 epoch 每材料为锚一次，从拟合集随机抽取两名非自身参考，按表型距离确定正负；两参考允许重复，与官方 flag=0 的抽样边界相同。softplus 三元组损失先归一化embedding，margin为clip(0.1*远表型距离/(近表型距离+0.01),0.1,0.9)。所有距离和margin均为[B]，修正原[B]与[B,1]的广播。验证三元组预先按种子固定，仅用于5个epoch中选最小验证损失；不对验证行反向传播。保留官方ReduceLROnPlateau(patience=5)，本次5轮预算不会触发降学习率。非完整训练batch若不足2行跳过以满足BatchNorm。

阶段二冻结编码器，在eval下L2归一化材料嵌入，关系值为 `1-distance/max_fit_pairwise_distance`。参考列只包含拟合集、顺序保持拟合集ID顺序；最大距离只由拟合集配对求得。查询可能比训练最大距离更远，关系允许为负，不用查询重缩放或裁剪。训练对角关系保留，关系向量不包含参考表型。验证材料仅作为查询；推理无需其表型。同一划分、环境、种子的关系编码器与关系特征供八个候选复用，不跨划分复用。

标记支路保留原分位数TabM的训练内标准化、成员缩放和全部隐藏块，取原输出头之前的成员隐藏表示。关系支路采用官方RepGeno(n_fit→4w→w)，BN/LeakyReLU(0.05)/dropout(0.6)，向各成员广播。两路分别调用官方CrossInformationFeatureFusion(2w→4w→w)，用同一个更新前的拼接向量做双向残差更新。融合BN把材料和成员轴展平，统计量只在训练batch更新。两路更新后拼接，经2w→w、BN、LeakyReLU、dropout(0.6)送入原TabM的成员输出头。每成员99分位点，原0.001..0.999等距网格，pinball沿分位点求和、材料成员平均，推理取成员及分位点算术平均。四环境独立。

开发预算：既有10外折×3内划分×4环境×2种子=240次关系预训练；对应原八组结构/学习率/weight decay共1920次分位数预测拟合。沿用500 epoch上限、patience50、batch128、梯度裁剪5。阶段二按单模型验证PCC选择checkpoint；每外折每环境按三内划分、双种子预测平均PCC选择配置。原分位数和原固定融合使用已有同折预测，不重训、不改融合权重。新候选自身不包含ICM，不能用其与ICM再融合掩盖单网络结果。

在看开发结果前限定推进规则：完整候选开发宏PCC超过原分位数0.494565432，且RMSE不高于0.871241630、MAE不高于0.672710044时，再冻结配置及两阶段轮次进行80次外层完整重拟合；否则结束本配置的开发评价。正式代码以同一结果文件中完整精度的原分位数参照比较，文字小数仅便于阅读。外层中关系预训练轮次取已完成三个内划分同种子的中位数，阶段二轮次取被选配置同种子的中位数；全开发集重拟合不再看测试做选择。完成训练后测试只评分一次。开发划分和外层历史均已多轮使用，结果按项目同协议比较解释。

输出包括240个关系编码器权重及SHA、拟合参考数/尺度、逐轮关系损失、1920条拟合记录与最优state摘要、验证完整分位曲线和点预测、配置选择与三项指标。大型产物仅留omen；正式小结果和文档自动推送。必要验证只覆盖损失形状、fit-only关系、冻结编码器复用、双路梯度和可复现初始化，不添加新基线或机制消融。
