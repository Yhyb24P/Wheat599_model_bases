# Wheat599 独立分位数 TabM：开发比较

四个环境分别使用完整 1,279 标记和官方 TabM 骨架，拟合集内标准化。每个成员输出 99 个均匀分位点（0.001 至 0.999）；pinball 损失先对分位点求和，再对材料和成员取均值。预测对分位点和成员取均值，反标准化后对两个种子平均。99 是为 Wheat599 有限预算选定的近似网格；作者公开实验示例使用 1,024 个分位点，因此本实验不是该配置的逐项复现。

沿用 `environment_tabm.yaml` 的八组容量、优化与正则配置（含学习率 0.0005 和 0.002），每个环境单独按三个内层验证集的双种子平均预测 PCC 选配置；每次训练按对应环境验证 PCC 选 checkpoint。沿用原训练批次、500 轮上限、50 轮耐心与梯度裁剪。30 内层单元 × 4 环境 × 8 配置 × 2 种子 = 1,920 次拟合。学习率与其他配置仍有绑定，因此不单独归因于学习率或网络容量。

只使用训练行拟合标准化；验证行仅用于 checkpoint 和配置选择。参考系统使用相同开发单元的 Huber ICM、四独立 TabM 及两者固定等权融合；开发数据既用于选模又用于报告，不是独立外层成绩。预设阶段只比较完整系统，不训练其他数据集，不访问外层测试标签。

实现依据：[作者的分位数回归实现（固定提交）](https://github.com/yandex-research/tabular-regression/blob/79e273f1af14c9a9703a1f385e9c9ea8faf5bae0/bin/quantile_regression.py)。
