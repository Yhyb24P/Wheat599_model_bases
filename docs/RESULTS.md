# Results — Wheat599 FT-Transformer 评价

**状态（2026-10-30）：** 已固定 `build_model()` 前的初始化种子；完成 A 架构的 40 次正式训练、同一训练轨迹内的 val-PCC / val-RMSE 双 checkpoint 比较，以及同折 RR-BLUP 对照。旧 C-order 结果全部无效；D 保留为探索性结果。负结果未改变：两种 checkpoint 规则都低于同折 RR-BLUP。

## 协议与可复现性

- 数据：BGLR `wheat.RData`，SHA-256 `8710523389007dd8b7c88a5deb74ee16aea0bae158496bc11f0626fb43b5ea21`；599 × 1279 DArT 0/1 标记；环境列 `"1"`、`"2"`、`"4"`、`"5"`。
- 划分：seed 42；10 折，test 9×60 + 1×59，val 54，train 485/486；四环境共享同一折，每个材料恰好测试一次。
- 训练：每折 Train-only StandardScaler（X 与 Y）；100 epochs；batch 8；AdamW；学习率按 val RMSE；预测反变换后计算指标。
- 初始化：每次 `build_model()` 之前设置 `random`、`numpy`、`torch` 种子；模型初始化不再依赖调用方遗留的 RNG 状态。每个（环境，折）只训练一次。
- Checkpoint 规则：在同一条训练轨迹中分别保留“验证 PCC 最高”和“验证 RMSE 最低”两个状态；两个规则在测试前固定，test 只作评价，不用来选规则或拼接环境最优结果。
- 指标：PCC、RMSE、MAE、预测标准差、预测标准差/真实标准差。表中为 10 折均值 ± 样本 SD（ddof=1），另有明确标注的中位数。10 折共享材料，不独立；只作描述，不做 p 值或置信区间。

固定种子后的 val-PCC 规则宏均为 PCC 0.4342、RMSE 0.9454、MAE 0.7387；旧 A（未显式固定初始化）为 0.4341、0.9455、0.7388。两者 39/40 折在四位小数上相同，1 折最大差异 0.0042；种子修正主要保证可复现，没有改变总体结论。独立进程重跑 fold 0（4 环境 × 2 规则）的 test PCC、RMSE、MAE、预测 SD 和 checkpoint epoch 完全一致（最大绝对差 0）。

**配对差（RMSE 规则 − PCC 规则，40 折）**

| 指标 | 均值 | 中位数 | Q1–Q3 | RMSE 规则更优折数 |
|---|---|---|---|---|
| ΔPCC | **−0.0040** | 0.0000 | −0.0255 到 +0.0130 | 13/40 |
| ΔRMSE | **−0.0212** | −0.0018 | −0.0507 到 +0.0023 | 20/40 |
| ΔMAE | **−0.0194** | −0.0071 | −0.0570 到 0.0000 | 21/40 |
| Δ预测 SD | **−0.1143** | −0.0217 | −0.2013 到 +0.0014 | 20/40 更低，10/40 更高，10/40 相同 |

- Checkpoint 纪元：10/40 折两规则相同；30/40 折不同，其中 RMSE 规则更早 17 折、更晚 13 折（差值中位数 0，均值 −3.8，范围 −39 到 +4）。
- 验证 RMSE 规则把验证 RMSE 宏均从 0.9306 降到 0.8849，但验证 PCC 宏均由 0.4465 降到 0.4002；test RMSE 只从 0.9454 降到 0.9242，val→test 的 RMSE 差距从 0.0148 扩大到 0.0393。验证集选择没有等量迁移到 test。
- 4/40 折 PCC 规则选到近常数 checkpoint；这些折改用 RMSE 规则后，预测 SD 和 test PCC 都上升（例如环境 4 折 4：SD 0.010→0.326，PCC 0.364→0.446），但 test RMSE 在该折由 0.895 升到 0.934。环境 2 折 5 则同时改善（SD 0.086→0.459，PCC 0.362→0.482，RMSE 1.032→0.945）。
- 排除 8 个任一规则出现近常数预测的折后，ΔRMSE 仍为 −0.0225、ΔPCC 为 −0.0082、Δ预测 SD 为 −0.091；RMSE 规则降低误差的同时仍降低相关和幅度，不是由少数退化折单独造成。
- 因此：PCC-only checkpoint 选择确实可以在少数折导致近常数预测；但 min-RMSE 规则并不恢复预测幅度，整体反而更收缩，并且用 PCC 换取 RMSE。两种规则没有任何一种同时改善幅度、PCC 与 RMSE。

## 同折 RR-BLUP 对照

RR-BLUP 使用同一 seed-42 折；X/Y 只用训练折中心化，alpha 只用验证折选择，test 只评一次。

| 环境 | PCC | RMSE | MAE |
|---|---|---|---|

40 个同折配对差：

- val-PCC 规则：ΔPCC **−0.0186**（PCC 更高 16/40），ΔRMSE **+0.0497**（RMSE 更低 14/40），ΔMAE **+0.0419**（MAE 更低 13/40）。
- val-RMSE 规则：ΔPCC **−0.0226**（PCC 更高 14/40），ΔRMSE **+0.0285**（RMSE 更低 14/40），ΔMAE **+0.0225**（MAE 更低 12/40）。
- 分环境 val-PCC 规则 ΔPCC：环境 1 +0.0167，环境 2 −0.0526，环境 4 −0.0082，环境 5 −0.0302；环境 1 的 PCC 优势同时伴随 RMSE +0.0097、MAE +0.0141（均更差），不构成稳定优势。

结论：两种 checkpoint 规则都没有达到同折 RR-BLUP 的 PCC；RMSE 规则缩小 RMSE 差距，但扩大 PCC 差距。负结果不变。

## 聚合口径

正式表按折均值报告。val-PCC 规则：折均 PCC 0.4342，合并 OOF PCC 0.3943；val-RMSE 规则：折均 0.4302，合并 OOF 0.3824。差异来自折间预测均值/尺度不同，是聚合口径差异，不是模型性能差异。折内 z-score 只改变合并尺度，不能作为性能恢复证据。跨折材料复用与折间相关仍使所有区间不可作独立推断。

## 无效结果

2026-10-29 发现 R `as.vector(matrix)` 为列主序，而旧 Python loader 按 C-order 重塑，导致 X/Y 被打乱。`src/wheat599/data.py` 已改为 `reshape(shape, order='F')` 并加 cache layout stamp；全量 R/Python 对照与非方阵测试通过，见 `docs/DATA_FACTS.md`。所有旧 C-order 结果目录均写有 `INVALID.md`，不得引用为性能证据。

## 限制

- 10 折共享 599 个材料，不独立；单 seed（42），初始化已固定但未估计种子/初始化方差；只作描述，不做 p 值或置信区间。
- 四个环境产量相关，不是四个独立重复；环境间比较只作描述。
- 没有外部独立测试群体；所有 test 材料都曾出现在其它折的训练集中。
- marker-only，不使用谱系 A；不声称生物学上位互作、因果标记或育种收益。
- FT-T 落后 RR-BLUP 只支持“该配置下预测精度较低”，不能单独归因于逐标记注意力机制；也未穷尽 FT-Transformer 的其它配置。
- 近常数预测的成因未完全分离：PCC 对尺度不敏感、验证集波动、MSE 收缩和早期 checkpoint 选择都可能参与；本比较只说明 checkpoint 选择是少数折的触发因素之一，不是低幅度的唯一原因。
