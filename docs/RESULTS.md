# Results — Wheat599 FT-Transformer 评价

**状态（2026-10-30）：** 已固定 `build_model()` 前的初始化种子；完成 A 架构的 40 次正式训练、同一训练轨迹内的 val-PCC / val-RMSE 双 checkpoint 比较、同折 RR-BLUP 对照、固定 RR-BLUP + A 骨干的残差修正首轮，以及共享低秩编码 + 双向诱导注意力 + 多槽读出的完整 FT-T 重构首轮。残差修正未观察到相对 RR-BLUP 的可复现增量（点估计 PCC −0.0011、RMSE +0.0218）；完整重构宏均 test PCC 0.3382、RMSE 0.9764，预注册 GO=False。旧 C-order 结果全部无效；D 保留为探索性结果。

## 协议与可复现性

- 数据：BGLR `wheat.RData`，SHA-256 `8710523389007dd8b7c88a5deb74ee16aea0bae158496bc11f0626fb43b5ea21`；599 × 1279 DArT 0/1 标记；环境列 `"1"`、`"2"`、`"4"`、`"5"`。
- 划分：seed 42；10 折，test 9×60 + 1×59，val 54，train 485/486；四环境共享同一折，每个材料恰好测试一次。
- 训练：每折 Train-only StandardScaler（X 与 Y）；100 epochs；batch 8；AdamW；学习率按 val RMSE；预测反变换后计算指标。
- 初始化：每次 `build_model()` 之前设置 `random`、`numpy`、`torch` 种子；模型初始化不再依赖调用方遗留的 RNG 状态。每个（环境，折）只训练一次。
- Checkpoint 规则：在同一条训练轨迹中分别保留“验证 PCC 最高”和“验证 RMSE 最低”两个状态；两个规则在测试前固定，test 只作评价，不用来选规则或拼接环境最优结果。
- 指标：PCC、RMSE、MAE、预测标准差、预测标准差/真实标准差。表中为 10 折均值 ± 样本 SD（ddof=1），另有明确标注的中位数。10 折共享材料，不独立；只作描述，不做 p 值或置信区间。

固定种子后的 val-PCC 规则宏均为 PCC 0.4342、RMSE 0.9454、MAE 0.7387；旧 A（未显式固定初始化）为 0.4341、0.9455、0.7388。两者 39/40 折在四位小数上相同，1 折最大差异 0.0042；种子修正主要保证可复现，没有改变总体结论。独立进程重跑 fold 0（4 环境 × 2 规则）的 test PCC、RMSE、MAE、预测 SD 和 checkpoint epoch 完全一致（最大绝对差 0）。

## MSE 分解：改善的是校准，不是相关性

对每个（环境，折）分别计算
$\mathrm{MSE}=b^2+\sigma_y^2(1-r^2)+\sigma_y^2(k-r)^2$，其中 $b=\bar{\hat y}-\bar y$、$r=\mathrm{Corr}(y,\hat y)$、$k=s_{\hat y}/s_y$（标准差均为总体 SD，ddof=0），再对 40 个组合取平均；三项均为 MSE 单位。恒等式逐折成立，最大数值误差 8.9e-16；不是先平均 $r,k$ 再代入。

| MSE 分解项 | val-PCC checkpoint | val-RMSE checkpoint | 变化 |
|---|---:|---:|---:|
| 均值偏移 $b^2$ | 0.0533 | 0.0333 | −0.0200 |
| 当前预测方向留下的误差 $\sigma_y^2(1-r^2)$ | 0.7852 | 0.7868 | +0.0015 |
| 尺度失配 $\sigma_y^2(k-r)^2$ | 0.0632 | 0.0432 | −0.0200 |
| **总 MSE** | **0.9017** | **0.8632** | **−0.0385** |

对应 $r$：0.4342 → 0.4302；$k$：0.5555 → 0.4461。对固定预测方向，MSE 最优尺度是 $k^*=r$；val-PCC 规则的尺度高于其 $r$，val-RMSE 规则把 $k$ 拉近 $r$，所以 RMSE/MAE 改善主要来自均值偏移和尺度失配减少，方向项反而略差。

因此：

- **预测 SD 较小本身不是退化。** 在 $r\approx0.43$ 时，把预测强行恢复到表型全部波动（$k\to1$）会增加 MSE；目标应是提高可泛化的 $r$，不是让 $k\to1$。
- 4/40（val-PCC）和 5/40（val-RMSE）折的预测 SD < 0.1σ_y，属于近常数 checkpoint，单独记录，不与整体合理收缩混为一谈。
- “checkpoint 规则改善”应表述为“改善均值/尺度校准，未提高跨材料相关性”，不要说成“恢复预测幅度是目标”。

## 残差修正首轮：固定 RR-BLUP + A 骨干

这里的“A 骨干”指现有 FT-Transformer 架构标签，不是谱系矩阵 `wheat.A`；模型仍为 marker-only。首轮只改一件事：RR 预测固定，FT-T 学习标准化残差；不改 tokenizer、CLS、attention，也不扩参数搜索。

**实现边界**

- RR 分支复用当前 `fit_rrblup`：训练折中心化、alpha 只在验证折按 RMSE 选、训练折拟合后冻结。新 runner 重算的 40 折 alpha 与 `results/bimsgp_diag_fixed_20261029/per_fold_rrblup.csv` 逐值一致（最大差 0）。
- FT-T 目标：$z=(y-\mu_T)/s_T$、$b^z=(RR_T-\mu_T)/s_T$，训练损失为 $\mathrm{MSE}(z-b^z-g_\theta(x))$；最终预测 $\hat y=RR+s_Tg_\theta(x)$，不再加 $\mu_T$。
- 只把 `backbone.output` 最后一个 Linear 的 weight/bias 置 0；参数量仍为 247,425（运行前断言）。验证、学习率调度、checkpoint 都用合成后的总预测。
- RR-only 与 residual 的 val PCC 同路径比较；严格大于才选 residual，平局选 RR-only。test 在每个折的选择完成后只评一次；没有用 test 选分支或拼接环境最优。

**判读**

- 本轮未观察到相对 RR-BLUP 的可复现增量：PCC 点估计基本持平（−0.0011），RMSE/MAE 点估计更高；只有环境 1 的 PCC 与 RMSE 同时改善。单划分不足以判定修正更差，方向不作强断言。
- 相对现有 A 的点估计改善为 PCC +0.0175、RMSE −0.0279、MAE −0.0253，四个环境均同向；这仍属描述级，说明“固定 RR 起点 + 残差修正”比纯 FT-T 更接近 RR，但不足以支持其优于 RR。
- 选择率 40/40 本身是诊断发现：val 每次都偏好 residual，但 test 没有相应收益。test 在每个折只评一次，没有“拒绝”动作；应写成 val 偏好未迁移到 test，而不是 test 拒绝了修正。
- 验证 PCC 提升没有迁移到 test（val gain 与 test ΔPCC 的描述性相关 −0.109）；修正量越大，test RMSE 点估计增加越多（修正量/残差 SD 与 test ΔRMSE 的描述性相关 +0.435，折间不独立）。诊断与点估计提示残差分支主要增加了方差、未提高可泛化方向，但这只是描述性判断。
- 已知限制：验证集同时用于 RR alpha 和分支/epoch 选择；RR 训练预测是 in-sample，残差目标偏小；seed-42 划分已参与多轮模型开发。即使分数提高也不是独立确认。checkpoint 规则本轮未再优化；没有把泛化差距归因于 tokenizer、CLS 或 attention。未设 FT-only + zero-init 对照，因此相对 A 的差异不能单独归因于 RR 分支；它只是“固定 RR 起点 + 修正”这一组合的描述。

## 完整诱导注意力模型（首轮完整架构）

这里的“完整模型”指用户定义的共享低秩标记编码 → 双向诱导注意力 → 多槽注意力读出 → 表型回归；首轮不做模块消融、不做参数搜索、不以 test 选结构。模型 marker-only；“A”是旧架构标签，不是 `wheat.A`。

**实现与规模**

- Tokenizer：$t_j=b_j+x_jUc_j$；$d=64$、rank $r=16$；$b_j$ 81,856 + $c_j$ 20,464 + $U$ 1,024 = **103,344** 参数。
- 2 个独立双向诱导块：$H=\mathrm{MAB}(I,T)$、$T'=\mathrm{MAB}(T,H)$；$m=32$、4 heads、Pre-LN 残差、ReGLU FFN hidden 128；共 171,776 参数（每块 85,888）。
- 读出：4 个可学习 query 的 Pre-LN 多头注意力池化（无 FFN），展平 4×64，MLP 256→32→1；读出 17,152，回归头 8,257。
- **总参数 300,529**，相对 A 的 247,425 为 **+21.5%**；未加参数量匹配对照，比较按同数据/同折/同训练预算解释。
- 注意力分数（含 heads）**675,312/样本**；A 实际为 4×1280²（首块全注意力）+4×1280（末块仅 CLS）= **6,558,720**，比值约 **1/9.7**（若把 A 两块都按全注意力算才约 1/19）。
- 初始化：$b_j\sim N(0,0.01^2)$、$c_j\sim N(0,1)$、$U$ Kaiming-uniform；$b/c/U$ 在 weight-decay 组，LayerNorm/bias/latent/query 不衰减。

## 限制

- 10 折共享 599 个材料，不独立；单 seed（42），初始化已固定但未估计种子/初始化方差；只作描述，不做 p 值或置信区间。
- 四个环境产量相关，不是四个独立重复；环境间比较只作描述。
- 没有外部独立测试群体；所有 test 材料都曾出现在其它折的训练集中。
- marker-only，不使用谱系 A；不声称生物学上位互作、因果标记或育种收益。
- FT-T 落后 RR-BLUP 只支持“该配置下预测精度较低”，不能单独归因于逐标记注意力机制；也未穷尽 FT-Transformer 的其它配置。
- 残差首轮中，RR alpha 与 residual checkpoint 共用验证折；RR 训练预测是 in-sample，残差目标偏小；40/40 折选中 residual。这些使结果只在该协议下描述，不是独立确认。
- 完整诱导模型首轮按预注册 GO 判据为 NO-GO，未做模块消融或规则/配置重试；5/40 折出现近常数预测；参数比 A 多 21.5%；fold-0 test 在两次 smoke 中被观测，配置在 smoke #2 后冻结；全部为协议内描述性评价，不是独立确认。
- 近常数预测的成因未完全分离：PCC 对尺度不敏感、验证集波动、MSE 收缩和早期 checkpoint 选择都可能参与；本比较只说明 checkpoint 选择是少数折的触发因素之一，不是近常数预测的唯一原因。
