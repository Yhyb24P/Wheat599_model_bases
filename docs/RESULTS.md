**与原始报告及上次实现的差异：** 历史 ICM 实际使用训练标准化与 GLS 无惩罚截距；原始报告采用原始 Y 的训练算术均值截距。因此原始版本的 `γ=0, η_A=η_R` 只精确退化到**同均值截距的 ICM**，不能精确退化到历史 GLS ICM。以相同基础参数和 η=0.6、只用十折开发标签及测试标记计算预测时，均值版与历史 ICM 最大绝对差为 0.10645。原报告的帽子矩阵 LOO 固定全训练均值；若固定这个均值，其公式与逐样本删除核岭的残差最大差异约 `1.2e-15`，但该均值包含待留出样本标签，不能称为重新估计截距的严格 LOO。上次 GLS 修订版使用 GLS 条件 LOO，误差约 `1.3e-15`；两版均未使用外层测试标签进行选模。原始均值版零共享时与同均值截距的四个独立核岭在十折预测上的最大差异约 `3.1e-14`。

开发选择 `(η_A,η_R,γ)` 为 `(0.8,0,0)` 3 折、`(0.8,0.3,0)` 1 折、`(0.8,0.8,0.5)` 3 折、`(0.8,0.6,0.5)` 2 折、`(0.8,0.8,1)` 1 折；同截距 ICM 的 η 为 0.8 九折、0.6 一折。候选重拟合的条件 LOO 预测分数 q 四环境均值 ± SD 为 0.3284 ± 0.0188、0.2559 ± 0.0215、0.1831 ± 0.0097、0.2690 ± 0.0178；核权重 w 为 0.3532 ± 0.0935、0.3810 ± 0.1107、0.3319 ± 0.0938、0.3440 ± 0.0889。这些是经验校准统计，不是遗传力或遗传方差组成。

合并 599 条 OOF 后的四环境 PCC：原始均值 BH-LMC **0.55754／0.50744／0.43939／0.52927**，四环境宏均 **0.50841**；同截距 ICM 为 **0.55837／0.50320／0.43791／0.53292**，宏均 **0.50810**。此处是合并 OOF 口径，不与折均 PCC 混用。完整校准与候选选模见 `results/bh_lmc_original_selection_20261102/`；四对照逐折差、最终校准和 OOF 指标见 `results/bh_lmc_original_final_20261102/`。该划分经过多轮开发，本次是探索性复验。

**原报告机制判断的必要修正：** 现有结果不能证明普通 ICM 的可分离结构是性能瓶颈，也不能由 RBF 增益推断真实上位性；同一核的谱滤波分支对易，不意味着其必然无预测收益。报告中声称“只要 `η_A≠η_R` 或 `γ>0` 就必然不可约化”也不成立，例如某一分支权重为零时，该分支的 η 不影响核。此前 OOF 可靠性实现的非对角缩放是 `sqrt(r_t r_t')`，不是 `r_t r_t'`；不同带宽按核分组并分别构造半正定任务矩阵，本身不会使联合核失效。[Bonilla 等](https://proceedings.neurips.cc/paper_files/paper/2007/file/66368270ffd51418ec58bd793f2d9b1b-Paper.pdf) 的完全区组任务间传递抵消结论以无噪声为条件，不能直接等同于有正则化的当前实现。[Burgueño 等](https://acsess.onlinelibrary.wiley.com/doi/abs/10.2135/cropsci2006.09.0564) 研究了加性和加性×加性环境互作，但不能据此把本项目 RBF 预测分量直接认定为生物学上位性。

原报告将 Gianola 与 Schön 的文章列为 `Genetics`、DOI `10.1534/genetics.115.185850`；该文实际发表于 *G3*，正确 DOI 为 [`10.1534/g3.116.033381`](https://pubmed.ncbi.nlm.nih.gov/27489209/)。

这些权重是在各自训练折核归一化后，由初值 `[1, 0.5, 0.5]` 出发、最多 12 步联合优化并按条件 LOO 选取的系数；不同核相关且 RBF 带宽可变，权重高低不能直接解释为独立预测贡献或生物学方差。完整模型在当前划分上获得增量，但这一比较不能单独归因于 RBF 分量；这些外层折已多次用于模型开发，结果属于探索性证据。

**RBF 相似性尺度。** 实际定义为 `exp(−h × Hamming距离 / d₀)`，其中 `d₀` 是训练材料两两 Hamming 距离的中位数。十个完整开发集的 `d₀` 为 432–437；当 `h=4` 且距离等于 `d₀` 时，相似性为 `exp(−4)≈0.0183`。此时开发集不同材料之间相似性的第 90 百分位约为 0.052–0.055；测试与开发材料之间的中位数约为 0.016–0.020。第 0 折开发集 RBF 核的非对角部分 Frobenius 范数为对角部分的 1.44 倍，故不能将整个核简单视作单位矩阵。

三个候选带宽的核对角线均为 1；固定 RBF 系数时，对角项相同，带宽改变的是非对角相似性及预测时的测试–训练相似性。34/40 个开发单元选中 `h=4`，体现内部验证更倾向候选中快速衰减的相似性结构；但系数与门控会随带宽联合优化，不能将该选择仅归因于对角正则化。非对角矩阵有明显结构，也不单独证明其提供增量预测信息。

**研究表述：** 在 Wheat599 当前划分上，联合建模加性遗传关系、背景条件化效应与局部核相似性的三核模型，取得了优于既有背景模型及主要对照的预测表现。内部选择倾向快速衰减的 RBF 核；其独立贡献与生物学机制不能由当前结果确定。

## MSE 分解：改善的是校准，不是相关性

对每个（环境，折）分别计算
$\mathrm{MSE}=b^2+\sigma_y^2(1-r^2)+\sigma_y^2(k-r)^2$，其中 $b=\bar{\hat y}-\bar y$、$r=\mathrm{Corr}(y,\hat y)$、$k=s_{\hat y}/s_y$（标准差均为总体 SD，ddof=0），再对 40 个组合取平均；三项均为 MSE 单位。恒等式逐折成立，最大数值误差 8.9e-16；不是先平均 $r,k$ 再代入。

| MSE 分解项 | val-PCC checkpoint | val-RMSE checkpoint | 变化 |
|---|---:|---:|---:|
| 均值偏移 $b^2$ | 0.0533 | 0.0333 | −0.0200 |
| 当前预测方向留下的误差 $\sigma_y^2(1-r^2)$ | 0.7852 | 0.7868 | +0.0015 |
| 尺度失配 $\sigma_y^2(k-r)^2$ | 0.0632 | 0.0432 | −0.0200 |
| **总 MSE** | **0.9017** | **0.8632** | **−0.0385** |

对应 $r$：0.4342 → 0.4302；$k$：0.5555 → 0.4461。对固定预测方向，MSE 最优尺度是 $k^*=r$；val-PCC 规则的尺度高于其 $r$，val-RMSE 规则把 $k$ 拉近 $r$，所以 RMSE/MAE 改善主要来自均值偏移和尺度失配减少，方向项反而略差。

因此：

- **预测 SD 较小本身不是退化。** 在 $r\approx0.43$ 时，把预测强行恢复到表型全部波动（$k\to1$）会增加 MSE；目标应是提高可泛化的 $r$，不是让 $k\to1$。
- 4/40（val-PCC）和 5/40（val-RMSE）折的预测 SD < 0.1σ_y，属于近常数 checkpoint，单独记录，不与整体合理收缩混为一谈。
- “checkpoint 规则改善”应表述为“改善均值/尺度校准，未提高跨材料相关性”，不要说成“恢复预测幅度是目标”。

## 残差修正首轮：固定 RR-BLUP + A 骨干

这里的“A 骨干”指现有 FT-Transformer 架构标签，不是谱系矩阵 `wheat.A`；模型仍为 marker-only。首轮只改一件事：RR 预测固定，FT-T 学习标准化残差；不改 tokenizer、CLS、attention，也不扩参数搜索。

**实现边界**

- RR 分支复用当前 `fit_rrblup`：训练折中心化、alpha 只在验证折按 RMSE 选、训练折拟合后冻结。新 runner 重算的 40 折 alpha 与 `results/bimsgp_diag_fixed_20261029/per_fold_rrblup.csv` 逐值一致（最大差 0）。
- FT-T 目标：$z=(y-\mu_T)/s_T$、$b^z=(RR_T-\mu_T)/s_T$，训练损失为 $\mathrm{MSE}(z-b^z-g_\theta(x))$；最终预测 $\hat y=RR+s_Tg_\theta(x)$，不再加 $\mu_T$。
- 只把 `backbone.output` 最后一个 Linear 的 weight/bias 置 0；参数量仍为 247,425（运行前断言）。验证、学习率调度、checkpoint 都用合成后的总预测。

## 完整诱导注意力模型（首轮完整架构）

这里的“完整模型”指用户定义的共享低秩标记编码 → 双向诱导注意力 → 多槽注意力读出 → 表型回归；首轮不做模块消融、不做参数搜索、不以 test 选结构。模型 marker-only；“A”是旧架构标签，不是 `wheat.A`。

**实现与规模**

- Tokenizer：$t_j=b_j+x_jUc_j$；$d=64$、rank $r=16$；$b_j$ 81,856 + $c_j$ 20,464 + $U$ 1,024 = **103,344** 参数。

- 逐 epoch 轨迹（fold 0/4）：到第 100 epoch 训练 RMSE 降至 0.18–0.31，验证 RMSE 在早期最佳 epoch（0–8）后升至 0.99–1.32。该诊断不证明增加容量、正则化或样本量一定能缩小差距。

## 限制

- 10 折共享 599 个材料，不独立；单 seed（42），初始化已固定但未估计种子/初始化方差；只作描述，不做 p 值或置信区间。
- 四个环境产量相关，不是四个独立重复；环境间比较只作描述。
- 没有外部独立测试群体；所有 test 材料都曾出现在其它折的训练集中。
- marker-only，不使用谱系 A；不声称生物学上位互作、因果标记或育种收益。
- FT-T 落后 RR-BLUP 只支持“该配置下预测精度较低”，不能单独归因于逐标记注意力机制；也未穷尽 FT-Transformer 的其它配置。
- 残差首轮中，RR alpha 与 residual checkpoint 共用验证折；RR 训练预测是 in-sample，残差目标偏小；40/40 折选中 residual。这些使结果只在该协议下描述，不是独立确认。
- 完整诱导模型首轮按预注册 GO 判据为 NO-GO，未做模块消融或规则/配置重试；5/40 折出现近常数预测；参数比 A 多 21.5%；fold-0 test 在两次 smoke 中被观测，配置在 smoke #2 后冻结；全部为协议内描述性评价，不是独立确认。
- 近常数预测的成因未完全分离：PCC 对尺度不敏感、验证集波动、MSE 收缩和早期 checkpoint 选择都可能参与；本比较只说明 checkpoint 选择是少数折的触发因素之一，不是近常数预测的唯一原因。
