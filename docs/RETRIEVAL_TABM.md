# 全标记 TabM 的材料级检索增强

2026-11-05，用户授权实施。基线提交 `5d63183`。当前处于实现阶段，未启动正式训练；没有检索候选的预测结果。

## 研究问题与模型

保留全部 1279 个标记和官方 TabM 0.0.3 的成员机制。在成员中间表示后，使用同一映射空间的负平方距离选邻居，聚合训练参考材料的四环境标签编码与查询—参考 key 差异校正，将其加入成员表示，再经过剩余网络预测。成员损失分别计算后平均，推断平均成员预测。首版不加入对比损失、低秩入口或额外门控。

该机制依据 [TabR 官方代码](https://github.com/yandex-research/tabular-dl-tabr/blob/main/bin/tabr.py) 的标签编码和差异校正；[TabM 官方代码](https://github.com/yandex-research/tabm) 提供全标记基座。公式和成熟组件本身不构成原创证据。

## 数据边界与选择

复用 `results/get_icm_protocol_20261103/splits_manifest.json`。每个外层开发集沿用三内层 fit/val，参考库只能含当前 fit 材料及其四环境标签。预处理只拟合 fit；训练按材料 ID 显式排除自身；验证查询不提供表型，验证材料不入参考库。模型每次构建前设种子，参考编码须与当前权重一致，明确 dropout 模式并计入重编码成本。当前阶段不运行外层测试。

同一配置的两种子预测先平均，再计算每环境 PCC 的宏平均，继而平均三内层分数，作为每外层开发集的选模指标；并列取配置列表较前者。另报告逐种子 PCC 均值，不能将其称为预测集成成绩。早停逐轨迹使用验证宏 PCC，最高者优先、并列较早 epoch。所有开发数字均为条件选模描述。

## 预算与对照

三个神经臂：原始全标记 TabM、多成员检索、单成员四环境检索。每臂预定 8 配置 × 2 种子 × 10 个开发集 × 3 内层，合计上限 1440 条正式轨迹；每条最多 500 epoch、patience 50，种子 42/2026。配置列表须在正式运行前固定，覆盖深度、宽度、dropout 与优化；检索臂还覆盖邻居数。预算不因已观察成绩追加。以小型贯通测实际成本，不将贯通成绩作性能证据。

Huber ICM 沿用同协议并输出配对材料预测；TabM–ICM 融合权重只在开发层确定，选择分数标为条件分数。保存每条轨迹的材料 ID、预测、配置、种子、划分、最佳 epoch、失败与成本，明确区分逐种子均分和真实种子集成。权重与大预测产物不入 Git。

[RAGP 原论文](https://doi.org/10.1186/s13007-026-01574-x) 是直接相关参照。公开源码核对版本为 `85675b1e8054fe3e91fdb3e974150f1dde81eee3`；其 Wheat599 配置使用 PCA95 输入、逐环境单输出、Pearson 损失、triplet 对比目标、cosine top-5、特征融合系数 0.4 和邻居标签乘 0.01。须单独作同协议适配，不能以多环境单成员检索替代。PCA 只在 fit 拟合；其 cosine 库更新通过减单位阵抑制对角而非严格排除，适配需改为材料 ID 严格排除，并记录与上游的差异。正式实现与预算尚待完成，论文原划分分数不用于本协议排名。

## 协作

gpt66：统筹、检索核心实现、配置、CLI、文档、Git，以及 Huber ICM 融合集成。gb：`src/wheat599/retrieval_run.py`、`tests/test_retrieval_run.py` 与正式执行。cn 已确认未写检索核心文件并交接，改分配 `src/wheat599/ragp.py`、`tests/test_ragp.py` 的独立参照实现。gpt6 已说明本轮未占用共享文件且暂不参与实现。共享文件保持一个写者。

首版实现将检索插在第一官方 block 后，剩余 blocks 为预测网络；查询与参考的第一个 block 均关闭 dropout，后续 blocks 保留训练 dropout。没有参考 key 缓存，每次前向重新编码且保留梯度。fit 局部行 ID 与参考库一一对应用于自身屏蔽。随机数据 CUDA 全尺寸贯通由 gb 完成，context 8/32 峰值分别约 394/1358 MiB，正式三臂预计 1.5–2 小时，非性能证据。

RAGP 的 omen 探针峰值 reserved 3810 MiB；仅为成本证据。其正式配置在 `configs/ragp.yaml`：8 配置 × 2 种子 × 30 内层，共 480 条，含官方 15 epoch 默认及 50/100 epoch、学习率、weight decay、dropout 选择，官方四环境宽度不变；Adam、gamma 0.95，patience 30。尚待 runner 完成与提交冻结，不因探针完成称正式训练已开始。每 epoch 更新库后才允许选 checkpoint，epoch 0 空库不参与选择。best state 暂存在内存，重载核对预测后流式记录 SHA，不保存每条约 720 MB 的权重文件。Triplet 索引错位作明确修正，并记录为相对上游的差异。

RAGP runner 与合成测试已完成，真实开发材料的小型连通测试仅在 `/tmp`，不作为性能证据；正式预算预计 90–120 分钟。runner 的 `best_epoch` 从 0 编号，其中 0 指首个完整训练 epoch 和库更新之后，不是未训练空库状态。选模异常必须记录失败并中止，不能标记为完整完成。正式执行在 omen 串行接续三臂与融合，等待冻结标签后启动。
