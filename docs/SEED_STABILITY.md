# Wheat599 固定选模多种子比较

在已使用的十外折上固定五个种子 `[42, 2026, 7, 19, 123]`，分别重拟合分位数 TabM 与 MoEGP 官方共享专家，各 200 次。MoEGP 复用每折每环境已选配置、训练轮数和学习率轨迹；分位数 TabM 复用已选配置，统一将原两种子共六个内折最佳轮次的中位数向上取整作为各种子的轮数。该统一轮数可能不同于原方案分别对每个种子取中位数；它用于稳定性诊断，不替换原冻结双种子系统。

每个种子的分位数预测与已冻结同折 Huber 各占 50%；与相同种子的单模型 MoEGP 配对。主报告先分别计算每种子的 40 环境折宏 PCC、RMSE 和 MAE，再对五个种子的指标取算术平均，并列出全部种子结果；不根据测试成绩挑种子。所有表型预处理仅拟合外层开发材料；不重新选配置、停止轮次或融合权重。原固定双种子融合 0.526506 另列，不能把五个单种子的分数平均当作预测集成结果。

该比较评估固定选模后的初始化／训练随机性，不等于对手已获得相同超参数选择预算，也不使重复使用的外折成为独立验证。预测和权重保留 omen，不入 Git。

## CWAGS 与谱系混合核核查

CWAGS 论文报告 Wheat599 四环境平均 PCC 0.5368，声明十折均值、固定随机种子、AdamW 与 400 epoch，但未在正文列出源码链接、实际折 ID 或完整选模信息；GitHub 仓库搜索 `CWAGS genomic` 未发现匹配仓库（2026-11-06）。因此暂不能忠实适配或作同协议排名；不以自行搭建的网络冒充作者实现。来源：[BMC Genomics](https://link.springer.com/article/10.1186/s12864-026-12980-9)。

混合核研究使用标记和谱系关系矩阵，其单环境 S5 属于额外信息输入类别；论文同时报告不同交叉验证方案，不与现有仅标记模型的十折结果直接排名。项目 `wheat.A` 的材料及谱系含义须与论文具体输入核验后才能直接比较；本轮不训练该模型。来源：[Frontiers in Plant Science](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2025.1605202/full)。
