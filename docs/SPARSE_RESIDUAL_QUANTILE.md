# 稀疏残差分位数网络

四环境分别训练；每个模型由全标记稠密入口、三个两层残差块及 32 个共享矩阵成员构成。仅残差块共享矩阵采用逐坐标预条件的 L1/2 近端，入口、输出头和成员适配使用常规 AdamW 衰减。输出 99 个分位点，沿用逐成员 pinball 损失求和及点预测平均。

开发比较沿用已有 10 个开发折、每折 3 个内部划分、两个随机种子和八个完整配置。宽度为 128 或 256，学习率为 0.0005 或 0.002，近端强度为 0.0001 或 0.001；候选按环境选择配置。两种子从头独立初始化并逐轮训练，每轮用两种子预测平均的验证 PCC 共同选择 checkpoint，禁止将各自最佳轮次拼接。第 0 轮不参与选模。其他训练设置沿用原分位数 TabM。

对照原分位数 TabM 和其固定 Huber 等权融合。性能与稀疏率分开报告，不能凭稀疏率声称提升。开发比较为探索性结果，不自行进入外层。

正式开发已完成 1,920/1,920 条、0 失败；候选 PCC 0.475179、RMSE 0.884523、MAE 0.683847，低于原分位数及固定融合。详细结果见 `docs/RESULTS.md`。本轮未保存 checkpoint 零比例。
