# Research Plan — Wheat599 模型基座比较

**状态：** 2026-10-29 协议草案，待团队评审与冻结；尚未运行正式实验。

## 1. 研究问题

**主问题：** 在 BGLR Wheat599 的四个环境上，采用无泄漏嵌套交叉验证，冻结的 TabPFN-3.5 上下文学习相对从头训练的小型 FT-Transformer、TabM、Gaussian RKHS、RBF-SVR 与线性收缩，是否在样本外 PCC 与 RMSE 上取得可重复的、超过方法间噪声的改进？

子问题：

1. 线性、核、非注意力神经、逐标记注意力、预训练 ICL 五类基座在四个环境与两种划分协议下的样本外排序是否一致？哪些差异超过配对不确定性（主区间为重复级）？
2. 若小型 FT-Transformer 优于线性模型，其增益是否也超过 TabM 与 Gaussian RKHS？即增益应解释为一般非线性，还是逐标记表示/注意力？
3. TabPFN-3.5 的增益是否稳定于默认的 8 成员 × 768 列 balanced 子采样与二值标记类别化处理？在强制数值化或全列覆盖变体下是否消失？

**证据等级（写作时必须区分）：**

- 预训练先验：TabPFN 胜出支持"预训练表格先验＋上下文学习＋集成/子采样"体系，不单独归因于标记间 attention。
- 逐标记注意力：FT-Transformer 只有在超过 TabM 与 RKHS 时，才支持"逐标记表示/注意力"的解释；仅超过线性模型只支持一般非线性收益。
- 生物学机制：本项目不做上位互作、因果基因或标记效应解释；排名不构成机制证据。

## 4. 评估协议

### 4.1 划分

- **随机协议：** 外层 5 折，重复 3 次（固定种子）；内层 3 折。分层变量 = 4 环境标准化 Y 的行均值的 5 分位 bin；每折的 4 环境 Y 均值与每行标记均值作为检查项写入 splits 表，不作分配约束。每个层随机起始 offset，层内轮询发折，保证折大小与层混合平衡。划分文件落盘。
- **IBS 臂（主亲缘协议，high-similarity family holdout）：** 相似性 $s=1-\mathrm{Hamming}/1279$，$s\ge0.8$ 建边，union-find 取连通分量；多线家族整簇入同一折，单例按固定种子随机 + 贪心补到最小折。外层 5 折目标 115–130（家族整簇可顶破，允许 ±10 并报告每折 $n$）；内层 3 折在 outer-train 内同约束递归装配。阈值 0.8 的结构性理由：使最大分量 ≤60 的最低阈值（44），12.4% 样本入家族；只用 X、不用 Y。IBS≥0.75 作为敏感性臂（最大分量 147，折目标放宽到 100–150 或巨簇单独成折）。
- **A 臂（探索性，close-relative holdout）：** $A\ge1.5$ 的连通分量；397 分量、77 个多线家族、46.6% 样本。A 只约束划分，不进入模型输入；A 臂读数解释为“标记模型对近亲家族留出的敏感性”，不进入主对比族。A=0.5 仍是 560 巨族，只在分量结构表留痕。
- **命名与限制：** IBS 臂报 high-similarity family holdout（阈值 0.8），A 臂报 close-relative holdout；“relatedness split”只作伞形词。巨大家族意味着“对远缘材料的泛化”在本面板上不可回答；IBS≥0.8 的单例在系谱上仍有 3 代内亲缘在训练折。报告家族成员-only 与单例-only 的分层指标。
- **$\Delta_{\text{arm}}$：** 逐模型逐环境计算 $\Delta_{\text{arm}}=\text{metric(random)}-\text{metric(IBS arm)}$，作为“近重复依赖度”的描述量；每线在两臂各有一条 OOF，线级配对差；推断地位与 A 臂同级（描述性）。
- 分量结构表写入 `results/<run>/splits/`；G1 测试：任何家族成员跨折 → FAIL；$s$ 与连通分量由固定种子可复现。silhouette 不适用，已弃用。
- 不把 `wheat.sets` 作为主协议；可作为单层 10 折敏感性分析与 BGLR 示例衔接。

### 4.2 无泄漏约束

外层留出折只用于最终预测与指标。以下全部在外层训练折内完成：

- 标准化/中心化、MAF 过滤（仅敏感性变体）、特征筛选；
- 核带宽、正则化参数、SVR 的 $C/\gamma/\epsilon$；
- 神经网络早停、学习率、权重衰减、层宽/深度选择；
- TabPFN 的配置选择（主结果固定默认配置，不做外层调参）。

内层选择指标 = RMSE（逐环境、3 折均值）；它与主报告指标 PCC 解耦：PCC 对仿射变换不变，选不出校准差异，因此用 RMSE 选择、PCC 与 RMSE 同时报告。早停后的 refit epochs = 各内折 best epoch 的中位数（上限 200）；优化器 AdamW、batch size 64、patience 20、max epochs 200。

`tests/` 包含 fold-local 合同测试与泄漏注入用例：故意实现全样本标准化 Ridge，协议测试必须失败；否则测试本身无效。Adapter 的 fit 只接收传入切片的副本，不得持有全量 data 引用；contracts 的声明-切片检查在实现层封死绕过路径。

### 4.3 指标与不确定性

- 每个环境、方法、重复计算 PCC、RMSE、MAE、R²；主指标 PCC 与 RMSE 同时报告；MAE 对 y 尺度变换不敏感、R² 在小折内噪声大，二者只作描述，不进判据。
- 每个材料在每个重复中恰好一个 OOF 预测；报告重复间均值与范围。
- **主要不确定度（重复级）：** 主族两臂（random、IBS 主亲缘臂）各做 10 次外层重复；每次重复得到 1 个“5 折配对差均值”（以线性收缩为参照，分别对 $\Delta$PCC、$\Delta$RMSE），10 个重复级值用 $t$ 区间（df=9）报告 95% 区间。探索臂（A、IBS≥0.75）5 次重复。该区间覆盖划分与重训噪声。
- **估计对象边界：** 重复级区间不包含“从更大群体抽取 599 份材料”的抽样误差；材料级 bootstrap 也不能补这一层（它条件于已有预测值）。两层都不覆盖群体抽样，报告中写明，防止把区间读成对更大小麦群体的推断。
- **次要不确定度（材料级）：** 在每个重复内对 OOF 预测做材料级配对 bootstrap（10,000 次，metric-aware：每次重抽后分别算两方法的 PCC/RMSE 再取差），每个重复各报一个独立 CI；不跨重复混池，也不把端点平均当作 95% CI。材料 bootstrap 只作描述。
- **亲缘臂子组：** 报告家族成员-only 与单例-only 的分层指标；聚合指标被单例主导，不能单独代表“高相似家族留出”的表现。
- **不把 CV 折当独立重复：** 重复级区间用于主判据，fold 级与材料级只作描述；不因折数多而制造小标准误。
- **预注册对比族（8 个）：** TabPFN vs $\{$linear, FT-Transformer, TabM, RKHS, SVR$\}$（5 个）；FT-Transformer vs $\{$linear, TabM, RKHS$\}$（3 个）。Holm 族边界 = 同臂 × 同环境 × 同指标内 8 个对比（PCC 与 RMSE 各自一族；环境不并族，跨环境聚合仍走 §6.1 的 3/4 判据）。A 臂、IBS≥0.75 敏感性臂、LightGBM secondary control 与 $\Delta_{\text{arm}}$ 只报告，不进 Holm 族，不出稳定结论；若 M1 显示 A 臂 informative，再以 amendment 升格。不以显著性阈值代替效应量。
- **$\Delta_{\text{arm}}$ 估计量：** 逐环境指标差的均值 + 两臂模型排名的 Spearman 相关；描述性，不进入主检验族。

### 4.4 敏感性分析

1. MAF≥0.05 列过滤（1183 列）与全列（1279 列）对比；主结果固定全列。
2. TabPFN 类别化变体：主结果固定 `auto_default`（`MIN_UNIQUE_FOR_NUMERICAL_FEATURES=4`，二值标记被判为类别特征）；`forced_numerical`（设为 2）只作为成对消融，不混入主结果。
3. 外层重复种子间的排序稳定性。
4. BGLR `wheat.sets` 10 折单层参考（不调参）；逐方法标注该臂是否可用（需要早停验证集的神经网络不适用），避免产出误导性的 NA。
5. IBS≥0.75 敏感性臂（最大分量 147；折目标 100–150 或巨簇单独成折）。
6. A 臂（A≥1.5）作为探索性第二工臂，不进入主对比族。

每次运行保存：配置快照、划分、OOF 预测、指标、依赖锁、代码提交、数据 SHA-256、随机种子、manifest。任何结果必须能由这些记录重建。

## 5. 模型网格（草案，冻结前确认）

| 模型 | 网格 |
|------|------|
| Ridge | $\alpha \in \{10^{-3},10^{-2},\ldots,10^{3}\}$（对数网格）；`fit_intercept=True` |
| 核岭 / GBLUP | $G=XX^\top/p$（未中心化＋截距；若用 VanRaden 惯例 $G=ZZ^\top/\sum2p(1-p)$，$\lambda$ 数值范围不同，等价测试须同式同 $\alpha$）；$\lambda$ 对数网格；与 Ridge 形式交叉校验 |
| Gaussian RKHS | $K=\exp(-d^2/(2\sigma^2))$，$d^2$ 为标记平均平方差；$\sigma^2$ 取材料间距离中位数的 $\{0.25,0.5,1,2,4\}$ 倍；$\lambda$ 对数网格 |
| RBF-SVR | $C\in\{0.1,1,10,100\}$；$\gamma\in\{\text{scale},0.001,0.01,0.1\}$；$\epsilon\in\{0.01,0.05,0.1\}$（以 `configs/stage2.yaml` 为准，48 配置） |
| TabM | 成员数 $k\in\{8,16\}$；宽度 $\{64,128\}$；学习率 $\{10^{-3},3\times10^{-3}\}$；权重衰减 $\{10^{-5},10^{-4}\}$；最多 200 epoch，内层早停 |
| FT-Transformer | $d\in\{16,32\}$；层数 $\{1,2\}$；dropout $\{0,0.1\}$；学习率 $\{10^{-3},3\times10^{-3}\}$；权重衰减 $\{10^{-5},10^{-4}\}$；最多 200 epoch，内层早停；二值标记编码 $t_j(0)=b_j$、$t_j(1)=b_j+w_j$；无位置编码 |
| TabPFN-3.5 | 冻结默认：`n_estimators="auto"`（8）、balanced、每成员最多 768 列、无全局投影；记录随机种子与配置 |
| LightGBM（secondary） | 预注册 secondary control，不进主族，CPU 运行；`num_leaves` $\{15,31\}$、`learning_rate` $\{0.05,0.1\}$、`min_child_samples` $\{10,20\}$；内层早停 |

核岭/GBLUP 是线性收缩的核形式等价检查，不单独作为报告臂；核心报告仍是六类：线性收缩、Gaussian RKHS、RBF-SVR、TabM、FT-Transformer、TabPFN。LightGBM 只作 secondary control；若 TabPFN/FT-Transformer 均不优于 LightGBM，则“新基座无增益”的结论强于任何族内显著性。

FT-Transformer 的 d=16/32、1–2 层是本项目针对 $n\approx480$ 的**自主小模型选择**，不是论文或 rtdl 包的默认配置。Gorishniy et al. (2021) 的 FT-Transformer 默认 3 层、embedding 192、8 头（Appendix E.2 Table 12），调参空间层数 $[1,4]$、embedding $[64,512]$（Table 13）；选择更小配置是为匹配训练材料量级并降低过拟合，不声称这是官方推荐。

各模型配置数不同（Ridge/核岭 7、RKHS 30、SVR 48、TabM 16、FT-Transformer 32、TabPFN 1、LightGBM 8）。若 FT-Transformer/TabM 相对线性或核方法不占优，须报告内层选择曲线与预算敏感性，排除“预算不足”的解释。Ridge 与核岭的等价性写成测试（同数据下 KKT 残差 <1e-8）；SVR 的 `scale` 只在 outer-train 上计算。M1 GPU 预算上限 20 GPU-hours；超过则停止并报告，不静默延长。

## 6. 判定标准

1. **先看配对区间，不看单点排名。** 只有主要配对区间（fold 级）排除 0，且满足操作化一致性：至少 3/4 环境的配对 CI 下界 >0 且没有任何环境的上界 <0，才称为稳定改进。
2. **区分"超过线性"与"超过非线性对照"。** FT-Transformer 若只超过线性，不称为注意力优势；TabPFN 若胜出，不称为标记 attention 优势。
3. **PCC 与 RMSE 同时看。** 相关性提高但 RMSE 明显恶化的模型，如实说明校准问题。
4. **划分敏感性。** 随机划分与亲缘簇划分的排序若不一致，结论限定在对应目标；不把随机划分的结果外推为"对远缘材料有效"。
5. **不把环境当独立重复。** 四环境分别报告；跨环境汇总只作描述，不做"环境数"显著性检验。
6. **负结果保留。** 若六类基座无稳定差异，结论是"在该数据与协议下未观察到可重复差异"，不是"所有模型等价"。

## 8. 限制

- **Wheat599 单数据集案例研究。** 599 份纯系、1279 个二值 DArT 标记；结论限定在该数据与四个环境，不外推到其它小麦群体或物种。重复级区间不覆盖“从更大群体抽取 599 份材料”的抽样误差。
- **远缘外推不可回答。** 巨大家族结构（A≥0.125 连通分量 577/599）意味着“对远缘材料的泛化”在本面板上不可回答；IBS≥0.8 的单例在系谱上仍有 3 代内亲缘在训练折。臂名使用 high-similarity family holdout / close-relative holdout，不用“亲缘簇外推”泛称。
- 四环境相关（如环境 2 与环境 4 样本相关约 0.66），不是四个独立重复。
- 无标记坐标；不构造位置编码，不把列序号当遗传距离。
- TabPFN 代码 Apache-2.0，3.5 权重非商用；结果只用于研究。
- 实现差异（正则化参数化、标准化默认值、求解器）只能减小、不能消除；写入 manifest。
- 基准精度不等于育种选择响应或经济收益。
