# TabICLv2 遗传任务适配：Wheat599 开发比较

本配置已完成，遗传续训低于官方权重及现役融合，未通过晋级条件；结果见 [RESULTS](RESULTS.md)。

固定官方 `tabicl==2.2.0` 回归权重；仅 Wheat599、现有 30 个内层划分，逐环境预测。三臂为官方权重、官方 graph-SCM 通用任务续训、遗传标记任务续训；后两臂每个内层拟合集各续训 50 个合成任务，初始权重、128 个上下文、32 个查询、学习率和优化预算相同。通用任务使用约 1,279 特征的官方 graph-SCM；遗传任务只从该内层拟合集整行无放回采样标记，混合稠密、稀疏和允许为零的非线性信号及噪声，表型完全合成；生成器不读取真实表型或验证／外层材料。模型训练采用官方回归分位数损失、bfloat16 与梯度裁剪，模型重计算节省显存。

直接使用全部 1,279 标记，无 PCA。三臂真实表型推断均调用官方回归接口，固定单个集成成员、相同随机种子，训练表型仅取拟合集；这是受控比较，不假称官方默认八成员。汇总同一材料上的原单独分位数 TabM、Huber ICM 与固定融合，按环境、内层单元和十个开发集等权汇总 PCC、RMSE、MAE；已冻结外层 0.526506 不与开发分数直接排名。仅开发，不使用外层测试决定模型。

官方预训练脚本使用 1–100 个特征；本实验是将合成任务尺度扩展到约 1,279 个特征的短预算对照，不保证 50 步足以充分适配。权重与许可见 [LICENSE_NOTES](LICENSE_NOTES.md)。
