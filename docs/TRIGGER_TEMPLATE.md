## 4. 指标规则（gb 裁决：OR，任一满足即触发）

- [x] **OR**：PCC 与 RMSE 各自判定；任一指标满足 ≥3/4 环境均值 >0 且跨环境均值 ≥1.2δ，即正向信号。
- 每指标用自己的 δ：δ_PCC（冒烟估计，兜底 0.03）、δ_RMSE（0.05）；先验化，禁看结果后改。
- **触发指标来源**（必填）：PCC / RMSE / 双。
- **对立形态**：若一指标过 1.2δ 而另一指标在 ≥3/4 环境 ≤ −δ，触发成立；负向指标入记录，Stage 2 判读必须处理该张力。
- **留痕带/弱信号**：两指标均未达 1.2δ，但任一指标跨环境均值在 [0.8δ, 1.2δ) 且 ≥3/4 环境同向 → 留痕、未触发。
- 第一眼触发只建立“进入 Stage 2”，不建立正向声称；“稳定改进”保留给 Stage 2 判据。
