# 完整教师块上的集成相关性蒸馏

本轮复用已完成MSE蒸馏教师，保持原分位数TabM四环境独立、各成员99分位点pinball监督。配置`configs/distill_correlation.yaml`，仍由`python scripts/run_background_nested.py --config ... --out ...`调用唯一distill_quantile实现。只训练学生，不重训教师。

辅助目标为`99*lambda/2*sum_g (n_g/n)*mean((Z_g(p)-Z_g(t))^2)`，p是成员和分位点平均的最终点预测，标准化沿完整教师留出块的材料轴进行。总体标准差ddof=0；学生均值/标准差不detach，教师固定。标准差分母clamp_min(1e-6)避免常数学生NaN；教师块SD<=1e-6显式失败。数值稳定下限活跃时不声称严格相关性等价。推理仍逐材料独立，无批间标准化。

每轮只打乱三个完整块的顺序，不拆块；逐块更新AdamW。每步完整损失乘`3*n_g/n`，使三个块的平均目标对应按材料数加权的完整pinball及蒸馏目标。lambda=0也采用相同批次、初始化、RNG与步数。学习率原值0.1倍，原weight_decay、裁剪5，100轮上限、patience20、PCC早停、保留epoch0候选。原checkpoint按原规则重建，并与历史预测逐元素核对，容差1e-6。

预算：30开发单元×4环境×2种子×4强度(0,0.01,0.1,1)=960微调，另240次必要原checkpoint重建。复用教师目标及参考划分，核对已提交诊断中的SHA、fit ID顺序、三块覆盖与训练/留出隔离。不读取当前验证/测试标签生成教师。

同时报告四个固定强度及每环境按三内折、双种子平均预测PCC选择的结果。参照：原分位数0.494565、旧固定MSE强度1的0.496191、当前同批次lambda0及冻结融合。预定有效候选条件：开发PCC超过上述参照，RMSE/MAE不劣于原分位数；不据标准差回升判成功，不追加搜索。即使开发满足条件，本轮也只交付开发比较，不自动启动新外层。现役冻结融合外层0.526506不变。
