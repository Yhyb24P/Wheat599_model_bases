# Wheat599 联合 TabM–Huber ICM 开发实验

只使用既有十个外层开发集中的三个内层划分；每个单元使用既有选择的四个独立环境 TabM 配置和 Huber ICM 配置，两个种子、固定残差和联合拟合各一条轨迹，共 120 条。两组使用相同网络、零输出初始化、Huber 损失、优化器及最多 500 轮、耐心值 50；每个种子依据四环境验证宏 PCC 选择整个系统的 checkpoint，然后对两个种子预测取平均。每折三次验证的宏 PCC 再取平均。外层测试材料不参与。

每次网络更新时，联合组在完整拟合集上按逐成员损失重新求解共享的凸 Huber 核分支，固定组沿用初始 Huber 分支。训练时网络 dropout 保持原选配置；核分支依据当次训练前向结果求解，验证时网络使用评估模式。环境成员数不同时对每个环境各自平均。核矩阵、任务协方差、标签标准化、惩罚和 Huber 阈值仅由拟合集及既有选择确定，不随网络更新。优化器的梯度收敛判据与原 Huber 实现相同；零网络使用相同初始化和求解路径。

比较原 Huber ICM、已选四独立 TabM 的双种子预测、两者固定等权融合，以及两个新系统。已有模型配置选择使用相同开发数据，结果是开发证据。选择的配置、输入哈希、轨迹和失败状态均记录；不进行外层评价。
