# 材料—位点双向推断原型

状态：2026-11-04 首轮固定模拟学习及加性／二次核参照已完成，原型整体未超过固定核，当前参数化开发结束。不追加训练或门控消融，未进入 Wheat599 评价；依据见 [RESULTS.md](../RESULTS.md)。以下保留实际实现和实验定义，供复现负结果。

## 研究对象与已有方法

模型学习从带表型的上下文材料推断查询表型。网络权重先在独立模拟任务上训练；应用时，真实训练材料的 X/Y 是前向计算的上下文。每层重新访问原始标记矩阵，不预先把它替换成唯一的材料嵌入。网络输出直接预测，不依附解析 ICM 预测增量。

[GPFN](https://pubmed.ncbi.nlm.nih.gov/40811178/) 已提出基因组预测的模拟任务摊销推断，并报告植物数据结果。[LinearPFN](https://arxiv.org/html/2610.06580v1) 已覆盖主效应和成对交互，发布模型的预测变量范围为 2–30；其[官方实现](https://github.com/schiekiera/LinearPFN/blob/97ac4f970df655b12d40a3b4a35fa3b2264ce6dd/linearpfn/model.py)包含逐单元双轴注意力和可选原始成对统计量，相关输出头显式枚举位点对。因此，跨任务学习、双向矩阵计算和交互统计量均不能单独作为原创贡献。待检验的区别是保留原矩阵的隐式证据迭代与可学习收缩，以及它在大量标记下的预测价值。

仓库旧 `DirectPredictor` 的开发 PCC 0.04693 来自特定加性／RBF 混合先验、每单元 2000 步训练，不能归因为 1279→64 必然丢失二值信息。本轮普通上下文对照复用该类，但更换为下面的共同模拟任务、上下文标准化和预算；旧数字不充当新对照结果。

## 首版计算

仅用上下文估计 X 列均值和全矩阵中心化 RMS；Y 按环境用上下文均值和标准差标准化。输入为 Z、Y 和查询矩阵 Q；接口不接收查询表型。

对每个查询 z，初始化 H=[z, ZᵀY/n]W₀。每轮计算：

1. A=ZH/√p，映射回上下文材料。
2. V=Ψ([A,Y,A⊗Y])，其中乘积保留 d×q 通道。
3. M=ZᵀV/n；g=σ(MLP([H²,M²,H⊙M,RMS(M)]))。
4. H←(1−g)⊙H+g⊙(MW)，最后由 zᵀH/√p 线性读出 q 个环境。

W₀ 和 W 无偏置；Ψ、门控和读出参数跨位点、跨迭代共享。门控只读取位点符号翻转下不变的量；上下文材料和标记同步置换不改变输出，查询之间不传递信息。位点状态是计算状态，不是识别出的因果效应。

首版保留消息绝对幅度，不把每个位点或整个消息强制归一到旧状态的幅度。源码另提供 `sqrt_n` 和查询初始化除以 √p 的明确尺度选项，但本轮配置固定为原始 n 分母和未缩放查询，不做尺度网格。

初始化的查询通道会在读出中产生 ||z||²/√p 项；上下文矩 ZᵀY 也使后续 ZH 与 Z 相关。不能用独立随机量的方差推导保证整个网络随 p 稳定。缩放查询只能控制前一个确定项；实际训练有效性仍需检验。

若只保留 H=z、V=Y⊙(ZH/√p)、M=ZᵀV/n 和 zᵀM/√p，输出严格为 ΣᵢYᵢ(zᵢᵀz)²/(np)，即二次核标签加权统计。完整网络不因此等价于核岭：Zᵀdiag(Y)Z 依赖标签，通常也不与 ZᵀZ 对易。

更直接的机制边界是位点门控：若将门控换为只读取位点维度平方／乘积均值的共享门，所有状态通道仍留在 span{z, Zᵀ 的列}，预测可由 ZZᵀ、Zz、zᵀz、Y 及 n,p 表达。当前逐位点的 H²、M²、H⊙M 门控打破这一限制，提供依赖标记坐标的收缩；这项能力是否带来预测收益尚未验证。材料侧任意非线性和矩阵反复往返本身不足以证明保留位点状态的必要性。

固定 q 时，每层每个查询主要时间为 O(npd+(n+p)d²)，状态 O((n+p)d)，另存原始 Z。查询批量 m 会乘入时间和状态成本；实现没有 p×p 或 n×p×d 单元状态。尚未据此声称万级标记上的实际效率优势。

## 独立先验与固定学习预算

`matrix_tasks.py` 不读取真实基因型或表型。四类任务为密集加性、稀疏加性、只显式生成成对乘积，以及未观测二值因果位点的加性效应。最后一类只输出带随机翻转的代理标记，不把潜在因果矩阵直接提供给网络。 成对乘积使用上下文样本均值中心化；样本均值与总体均值的差异会引入总体加性分量，相关标记下乘积与加性也未必正交，因此不能称作边际信号严格为零的“纯交互”先验。

训练标记来自独立 Bernoulli 或随机分组的相关代理模型，最后打乱列并随机交换编码。效应包含随机跨环境共享和环境特异部分，噪声强度按配置抽取。信号幅度只由上下文特征几何确定，不按实现的效应范数或查询结果归一；常量上下文设计明确记录并保留。这些是计算先验，不是植物繁育过程的实证模型。

配置 `configs/matrix_inference.yaml` 固定：CPU 两线程；上下文数 {64,128,359}，标记数 {128,512,1279}，查询 8、环境 4；宽度 32、4 次共享迭代；两个种子，各 4000 步 AdamW。完整网络与普通上下文 Transformer 使用相同任务 ID 和更新步数，记录各自参数量与耗时，不声称参数量或 FLOP 完全相等。对照的三个历史先验参数输入固定为常数；其任务相关矩阵仅由当前上下文 Y 计算，不获得生成先验真值。

每 500 步及初始化评估预先固定的 32 个独立模拟验证任务，按平均标准化 MSE 选 checkpoint，同分取最早。另有 24 个未参与训练／选模的混合群体结构任务，只在选定后评价一次。训练目标为模拟的无噪声查询表型；上下文输入仍有噪声。逐任务保留 MSE、上下文均值预测误差、任务族、种子及生成参数；失败停止并记录。训练入口：

```bash
python scripts/run_background_nested.py --config configs/matrix_inference.yaml --out results/<新运行目录>
```

该入口只完成模拟学习检查，不生成 Wheat599 预测。它可以识别未学会推断的实现，但训练损失降低或超过普通 Transformer 均不够支持方法贡献。下面的加性＋二次核匹配比较已完成，原型尚未超过参照，未进入 Wheat599 内层开发评价。固定算子消融及现代神经对照 [TabM](https://proceedings.iclr.cc/paper_files/paper/2025/hash/c1ba41c694834aeef91ae161711d4939-Abstract-Conference.html) 尚未启动。

## 固定核参照

首轮神经结果尚未超过上下文均值预测的成对乘积任务，因此先比较标准推断，再决定是否修改迭代结构。沿用同一生成器和 32 个模拟验证任务：加性核 G=ZZᵀ/p，二次核 G⊙G；查询核采用相应内积。两核各自只按上下文中心化、归一为平均对角 1，再以二次核比例 {0,0.25,0.5,0.75,1} 混合。岭参数 {0.01,0.03,0.1,0.3,1,3,10,30,100}，解 (K+λI)α=Y，各环境独立读出。

仅按 32 个验证任务的平均无噪声目标 MSE 选择全任务族、全环境共享的超参，平分取配置中较早的候选；分别保留加性端点、二次端点及全混合候选的赢家。随后在原 24 个混合群体任务上评价选中方法。该面板已经参与失败诊断，这次仅作历史比较，不构成新分布上的确认。核参照不获得生成时的效应、遗传力或协方差真值，不读取 Wheat599。
