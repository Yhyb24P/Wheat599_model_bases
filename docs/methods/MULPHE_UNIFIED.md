原始方法核对：论文描述目标适配阶段平均源编码器特征，最后使用源预测标量进行注意力融合，且报告目标性状自身可获得注意力；当前公开默认入口的融合采用隐藏表示。因此应分别标明论文描述的标量融合与公开实现的隐藏融合，不能混称。论文称预训练、微调、融合上限为 500、300、200，而固定提交 `e20ca68` 的公开 `train.py` 默认是 300、300、200；本次“公开默认配方”以代码为准并记录这一差异，不声称恢复了论文实际运行。
