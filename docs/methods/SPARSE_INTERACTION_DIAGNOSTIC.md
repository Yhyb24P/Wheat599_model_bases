# 稀疏交互的有限诊断

本轮已完成，定位材料—位点网络的推断缺口；没有训练新网络或读取 Wheat599。沿用首轮的 32 个模拟验证任务与 24 个已查看的混合群体结构任务；后者是历史诊断面板，不是新的确认集。神经参照直接复用两个种子的逐任务误差，不做预测集成。结果归入 [RESULTS.md](../RESULTS.md)。

## 先明确能够证明什么

二值标记经上下文中心化、全局尺度 $s$ 标准化后，有

\[
Z_j^2-\overline{Z_j^2}=(1-2\mu_j)Z_j/s.
\]

所以平方内积核中的同位点平方项含加性成分。不同位点乘积核
$K_{pair}(z,q)=\tfrac12[(z^\top q)^2-(z^2)^\top q^2]$
是所有 $j<k$ 特征的内积；在相关标记下，这些特征仍可能与加性项相关。

用户提供的合法二值反例已由独立枚举复现：A 上下文为 `11011,01000,00010,10111`，查询 `01110`；B 上下文为 `10111,00100,00010,11011`，查询 `10000`；共同表型为 `[1,-1,1,-1]`。两者的上下文标准化材料 Gram、查询交叉 Gram、查询范数一致至浮点误差。在均匀位点对、等概率正负单位效应、方差为 1 的高斯观测噪声先验下，查询后验均值分别为 −0.5697611490、−0.1899203830。

这证明原材料 Gram 摘要可能遗漏预测信息。交叉项核的查询交叉块也在两组输入之间不同，但这不等于普通核岭已恢复后验差异：上下文中心化的未缩放交叉项核、岭参数为 1 时，给定上述表型的两个预测都为 0.5692599620。该反例不能证明神经网络的必要性；本轮仍需通过同特征稠密 L2 参照实际检验稀疏推断的收益。

## 相同可观测信息与目标

所有方法只由带噪上下文估计效应，评价标准化的无噪声查询目标。$Z,Y$ 采用原模拟任务的上下文预处理；$A=Z/\sqrt p$。$W$ 包含全部 $j<k$ 的 $Z_jZ_k$，每列仅按上下文中心化和 RMS 缩放，常量列置零，查询沿用同一统计量。

未知位置参照求解：

\[
\min_{B,C}\frac{\|Y-AB-WC\|_F^2+\lambda_A\|B\|_F^2}{2n}
+\lambda_G\sum_l\|C_l\|_2+\frac{\lambda_E}{2}\|C\|_F^2.
\]

组惩罚共享四环境的支持，不要求对应主效应显著。生成器当前有效对不共享端点，四环境共享有效位置；这只是本轮先验范围，不代表一般交互网络。未知位置求解器不接收真实支持或生成参数。

消去 $B$ 后，$e=Y-WC$、$M=\lambda_A(AA^\top+\lambda_AI)^{-1}$，数据项为 $\operatorname{tr}(e^\top Me)/(2n)$，不能误用 $M^2$。加性系数按 $B=A^\top(AA^\top+\lambda_AI)^{-1}e$ 回代。

已知位置参照只获得有效交互对，用同一目标、全空间的同一 λ_max、同一正则网格重新估计效应；其他任务族的已知支持为空。这是明确多给信息的诊断，不能作为实用预测器。它不获得真实系数、遗传力、效应协方差或查询信号。另用 sklearn 的多任务 ElasticNet 独立求解其小规模限制问题。

稠密参照使用相同 $W$ 的核，按上下文平均对角线归一化：$K_P=WW^\top/\operatorname{mean diag}(WW^\top)$，$K=AA^\top/3+K_P/r_P$，预测为 $K_* (K+I)^{-1}Y$。空 $r_P$ 直接退化为既有加性岭解。

## 固定预算与数值证书

配置为 `configs/sparse_interaction_diagnostic.yaml`，统一入口：

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 PYTHONPATH=src \
  python scripts/run_background_nested.py \
  --config configs/sparse_interaction_diagnostic.yaml \
  --out results/sparse_interaction_diagnostic_20261104
```

- 固定 λ_A=3（既有加性参照的选择）、λ_E=0.001；λ_G/λ_max 为 `1,0.5,0.2,0.1,0.05`，其中 λ_max=max_l||W_l^T M Y/n||₂。
- 未知位置与已知位置分别按全部 32 个验证任务平均 MSE 选择一个比例，同分按配置顺序取首项。稠密参照在 `null,0.01,0.1,1,10,100` 中同样选择一个 $r_P$。不按任务族、维数或查询逐项选择。
- 选择落盘后，历史面板仅评价选定参数。网络使用已冻结的首轮结果，不重训、不重新选 checkpoint。
- 活跃集只加实际违反 KKT 的候选，每轮最多 128 组。对全部不同位点对扫描，没有近似搜索遗漏；最多 4096 活跃组、64 外轮、每次内层最多 10000 次迭代。限额导致未收敛时显式失败，不能当作统计方法的负结果。
- CUDA float64，GPU 分配上限 20%，CPU/BLAS 线程 2；当前最大上下文 359、标记 1279。全候选 float64 特征约 2.19 GiB，分块构建，运行后释放显存。

非零组检查向量站停式 $s_l-\lambda_E C_l-\lambda_G C_l/\|C_l\|=0$，零组检查 $\|s_l\|\le\lambda_G$，其中 $s=W^\top Me/n$。KKT 绝对误差不得超过 $10^{-8}\max(1,\lambda_{max})$。同时计算精确对偶间隙：

\[
\mathrm{gap}=\lambda_G\sum_l\|C_l\|+\tfrac12\lambda_E\|C\|_F^2
+\sum_l\frac{(\|s_l\|-\lambda_G)_+^2}{2\lambda_E}-\langle C,s\rangle.
\]

它须不大于 $10^{-7}\max(1,|\mathrm{objective}|)$，实质负间隙判失败。未知位置证书覆盖全候选空间，已知位置证书只覆盖给定支持。

## 判读边界

已知位置也无收益时，不能据此评价搜索能力；已知位置有效而未知位置无效，只排除这套估计器和正则预算，不能声称信息论不可识别。未知位置有效而网络无效，才建立明确推断缺口。精确支持恢复只作解释，相关标记的替代位置仍可能预测正确。即使模拟诊断成功，也不能代替 Wheat599 上的优势。

相关算法本身已有成熟基础：[xyz](https://www.jmlr.org/papers/volume19/16-515/16-515.pdf) 讨论二值输入的交互搜索与全空间 KKT；[IntHT](https://proceedings.neurips.cc/paper/2019/file/3c7417b8df0daf23f39f445e740c7a43-Paper.pdf) 的稀疏二次回归保证有设计条件；[LISTA](https://icml.cc/2010/papers/449.pdf) 与 [mr.mash](https://journals.plos.org/plosgenetics/article?id=10.1371/journal.pgen.1010539) 已覆盖可学习稀疏推断及多元效应共享。这里实现统计参照，不将其命名为新神经架构。
